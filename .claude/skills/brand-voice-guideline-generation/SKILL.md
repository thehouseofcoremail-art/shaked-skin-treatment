# Brand Voice Guidelines Generation

Process input sources to produce a brand voice document with:

1. **Voice attributes**, 3 spectrum dimensions (e.g., "Clear, but not sterile")
2. **Lexicon**, approved phrases + forbidden terms
3. **Sentence rules**, length, active/passive, address (informal/formal)
4. **Examples**, 3x "sounds like us" + 3x counter-examples with explanation
5. **Open questions** flagged for stakeholder input

For heavy parsing across many sources, delegate to:
- conversation-analysis agent (Gong calls, meeting transcripts)
- document-analysis agent (Notion, Docs, brand decks)
- quality-assurance agent (validate completeness + PII before delivery)
